# 对话媒体遮挡海面

用户截图中的图片被鲸鱼、云影和水纹覆盖。根因是旧内容卡片扫描跳过 `IMG` 等媒体，且媒体通常没有不透明的 CSS 背景色；关闭毛玻璃和输入框避让时还会直接跳过整条测量路径。将图片作为毛玻璃卡片只能减淡海面，不能满足图片完整位于海面上方的要求。

[src/foreground.js](../../src/foreground.js) 独立收集当前对话滚动区域内可见的图片、视频与嵌入媒体，不依赖毛玻璃或避让开关。记录媒体边界、圆角与滚动视口交集，不修改图片、媒体透明度或页面层级。[engine.js](../../src/engine.js) 完成鲸鱼、水纹、风云、喷气与毛玻璃绘制后，最后按这些区域清除海面叠加画布，使原始 DOM 媒体完整露出。

重叠媒体使用同方向圆角路径的并集，避免重叠处重新露海。媒体加载、尺寸变化、滚动、显隐和删除会使几何失效；减少动态时单独安排一帧静态重绘。观察器仅绑定当前对话区域和可见媒体，处置时清理。布局扫描有 6000 节点、512 样式读取和 128 媒体区域预算；不在每个绘制帧重新遍历 DOM。

新增 [media-occlusion.test.js](../../tests/media-occlusion.test.js) 的 9 项回归，透明背景 GIF 与减少动态模式下的加载更新均在修复前失败，修复后通过。检查覆盖媒体种类、圆角重叠、最终绘制次序、开关无关性、隐藏与移除、静态更新和监听清理。最终完整 `pnpm verify` 通过 245 项测试，插件与预览产物和源码一致。

在真实可见浏览器的完整 `createWhaleLayer` 与 DOM 媒体复现中，修复前图片内有 94,242 个海面非透明像素。修复后深浅主题、毛玻璃开关四种组合各检查图片内部 223,104 个像素，海面残留均为零；图片外仍有海面像素。真实点击图片可达，移动后和系统减少动态下的区域仍保持零残留。原始证据见本地 [QA 摘要](../../.scratch/media-occlusion-20261023/qa-summary.json)、[修复前](../../.scratch/media-occlusion-20261023/before.png) 和 [修复后](../../.scratch/media-occlusion-20261023/after-light-plain.png)。

浏览器脚本中的图片隐藏采样未等待重绘，不能证明隐藏后实际像素恢复；该项由回归测试的帧推进与绘制命令覆盖。真实 DSH 对话窗口和安装后的热加载未直接验证，独立 DOM 复现与安装文件指纹不能替代这一证据。
