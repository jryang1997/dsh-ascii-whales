# ADR 0001：场景预设只拥有表内十个参数，1.0 新增项是保护值

状态：已接受（2026-10-31，随集成 PR #7）

## 背景

六票里的场景预设规格（`docs/specs/whale-experience-and-resource-mode.zh.md`）在 2026-10-25 确认时只有十个场景参数。之后 1.0.0 新增了默认开启的「海面方格」与「听写联动」，它们既不在场景表内，也没有被规格声明为保护项。合并时如果让场景预设接管这两个字段，就会悄悄改变已确认的组合表；如果完全忽略它们，则缺少"场景不重置它们"的可核对断言。

## 决定

- 场景预设只拥有已批准的十个字段：鲸数、游速、浓度、配色、风纹、云影、尾流与水花、喷气、落雨、雨量。
- 1.0 的 `seaGrid` 与 `dictationEcho` 是保护值：场景不修改、默认场景不重置它们的保存值。
- 省资源档保留这两个特性：照常绘制方格、以单次绘制响应听写事件，但不为它们保留高频循环；15 次/秒预算只约束稳定持续动画。
- `tests/presets.test.js` 的保护字段夹具显式包含这两个关闭值，场景应用后必须保持不变。

## 后果

- 规格文档补记了归属声明，预设测试覆盖保护语义；合并后构建的 45 单元测量用于确认预算未被抬高。
- 若将来希望"极简"预设关闭方格，需要先修改场景表并重新确认，而不是在实现里静默覆盖用户保存值。
