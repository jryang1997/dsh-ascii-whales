# 文字蓝鲸改进规格草案

状态：本地审阅草案，已按六票实施并合并到 1.0.0（合并提交 `336b41a`，合并后 `pnpm verify` 478 项通过、63 个测试文件）。真实 DSH、实际读屏与合并后构建的资源测量仍待完成，验收复选框保持未勾选。

来源：本轮审计讨论及用户确认的两组交付。本文描述目标行为与验收条件。预设数值、资源预算和测量流程均为草案建议，不是实测结果。逐项实施与验收状态见[六票实施与验收记录](./whale-implementation-evidence.zh.md)。

## Problem Statement

文字蓝鲸已经跟随会话、子代理和后台任务，但介绍主要强调画面效果。用户需要读到设置章节才容易发现任务跟随，首次使用也缺少状态图例。

状态徽记画在对辅助技术隐藏的装饰层内，没有等价的读屏信息。会话空闲与后台任务完成容易被误解为同一件事。

选择一种画面需要组合许多设置。用户已有的文字、阅读保护和布局偏好需要在切换场景、保存冲突及升级时保留。

动画已有约每秒 30 次的绘制节流、页面隐藏暂停和系统减少动态效果支持，但仿真仍逐个动画回调推进。目前没有可复现的资源比较，不能承诺省电或续航改善。

## Solution

第一组提供状态图例、等价文本状态、场景预设，以及围绕任务跟随组织的中英文介绍和演示。设置先提供场景选择，滑杆与细项放入高级设置。场景选择沿用配置草稿与保存流程。

第二组提供独立于场景的标准档与省资源档。省资源档减少持续调度、仿真和绘制工作，并采用慢漂移。系统减少动态效果优先，状态更新不依赖动画。交付包含可重复测量入口、原始结果、环境说明及汇总。

图例与无障碍、场景预设可独立验收。文案可先准备，最终截图和录屏依赖第一组交互完成。第二组按优先级后置，不以第一组演示为技术前提。完整资源比较依赖档位完成，测量工具和标准档基线可提前准备。第一组可独立交付。

## User Stories

1. 作为首次使用者，我希望先知道鲸群能跟随任务，以便判断插件的工作价值。
2. 作为首次使用者，我希望看到运行、等待回答和任务结束的演示，以便理解使用过程。
3. 作为首次使用者，我希望首次开启任务跟随时看到图例，以便理解符号。
4. 作为用户，我希望关闭首次图例后不反复看到它，以便继续阅读。
5. 作为用户，我希望设置中始终能重开图例，以便忘记含义时查阅。
6. 作为用户，我希望区分运行、等待、空闲、后台任务完成和失败，以便准确理解状态。
7. 作为用户，我希望子代理停止时不显示成功，以便不把暂停当成完成。
8. 作为用户，我希望首次进入时不播放历史结果，以便只关注新变化。
9. 作为多任务用户，我希望任务超过鲸数时仍有数量和紧急状态提示，以便不漏掉待回答任务。
10. 作为读屏用户，我希望获取名称和文字状态，以便不依赖 Canvas 或颜色。
11. 作为读屏用户，我希望相同状态不因动画重复播报，以便继续听取对话。
12. 作为键盘用户，我希望操作图例和场景不丢焦点，以便完成设置。
13. 作为用户，我希望关闭任务跟随后停止插件任务提示，以便只保留装饰。
14. 作为用户，我希望状态能力不可用时有明确说明，以便不把未知当成空闲。
15. 作为用户，我希望用少量场景完成常见调整，以便不逐一操作滑杆。
16. 作为用户，我希望选择场景只修改配置草稿，以便保存前比较效果。
17. 作为用户，我希望重新载入已保存值能放弃草稿，以便恢复正式背景。
18. 作为用户，我希望换场景保留鱼身文字和阅读习惯，以便不重复配置。
19. 作为高级用户，我希望全部原有配置仍可访问，以便细调画面。
20. 作为高级用户，我希望自定义标记准确反映参数，以便理解当前场景。
21. 作为用户，我希望保存失败或冲突时保留草稿，以便重试或主动重新载入。
22. 作为老用户，我希望升级保留已有配置，以便继续使用原画面。
23. 作为用户，我希望中英文场景、图例和状态含义一致，以便跟随宿主语言。
24. 作为笔记本用户，我希望独立选择省资源档，以便在喜欢的场景中减少持续动画工作。
25. 作为用户，我希望换档保留鲸鱼位置、任务身份和个人游速，以便保持连贯。
26. 作为等待任务的用户，我希望低帧率不延误状态提示，以便及时处理任务。
27. 作为减少动态效果的用户，我希望静态姿态仍更新状态，以便无需动画使用任务跟随。
28. 作为用户，我希望隐藏页面后停止动画推进，以便减少后台工作。
29. 作为用户，我希望滚动暂退和预览暂停停止对应计算，以便获得真实暂停。
30. 作为用户，我希望资源数字有环境和原始数据，以便判断本机成本。
31. 作为维护者，我希望同一入口比较关闭、标准和省资源条件，以便复查效果。
32. 作为维护者，我希望缺失指标和测量失败有明确记录，以便避免误导结论。

## Implementation Decisions

### 状态语义

下列来源与基本语义沿用当前实现。

| 状态 | 判定 | 视觉与等价文本 |
| --- | --- | --- |
| 运行中 | 宿主报告会话或子代理运行，或后台任务运行、停止处理中 | `···`；名称和运行中文字。停止处理中不提前报告完成 |
| 等待用户 | 宿主报告待回答、待审批或待计划审阅，优先于运行 | `!`；名称和等待处理文字。鲸鱼平滑回到水面，不开始新下潜 |
| 空闲或本轮停止 | 已有宿主状态，未报告运行或待处理交互 | 慢速滑行，无成功或失败结果；可查询空闲文字 |
| 后台任务完成 | 插件先观察到该后台任务运行，再观察到完成 | `✓`、名称及后台任务完成文字 |
| 后台任务失败 | 插件先观察到该后台任务运行，再观察到失败 | `×`、名称及后台任务失败文字 |
| 状态不可用 | 缺少必要宿主能力，或尚未确定当前会话 | 保留装饰，文字说明不可用，不猜测任务结论 |

不可用说明是新增目标，不将当前实现对缺失状态的回退行为视为已满足。取消、停止、断开和任务消失不自动等同于成功或失败。会话与子代理不新增成功推断。

能力缺失按来源分别降级，不因一项缺失隐藏其他有效状态。

| 能力情况 | 目标行为 |
| --- | --- |
| 无法确定当前会话 | 不绑定其他会话冒充当前会话，文本说明当前会话状态不可用 |
| 会话目录有效，实时状态服务缺失 | 目录中明确提供的运行事实可以展示；等待信息标为不可用，不把缺少信息判为空闲 |
| 某个实体没有足够状态 | 该实体显示状态不可用，其他实体照常展示 |
| 后台任务服务缺失或断开 | 会话和子代理状态继续工作，摘要说明后台任务状态不可用，不将任务消失当成结果 |
| 后台任务服务正常且返回空列表 | 表示没有当前可见后台任务，不显示服务不可用 |
| 用户关闭任务跟随 | 不显示缺能力警告，不为此恢复订阅或提示 |

只有来源明确提供足够状态时才显示空闲。已有图例与配置界面不因宿主缺少任务状态能力失效。

第一头优先对应当前会话，其余按身份稳定绑定。列表重排不无故交换。鲸数不足时第一头汇总额外数量及最紧急提醒。沿用等待用户、失败、完成、运行、空闲的优先级。

结果提示保留当前六秒仿真时间寿命。降低帧率、慢漂移或重建鲸体不能重置或延长提示。隐藏、滚动暂退、明确暂停和减少动态效果停止仿真时，提示时钟暂停。恢复不补算暂停时间，新状态事件仍能刷新静态提示。

历史结果首次读取不弹出，相同结果不重放，切换会话不带入旧提示或播报队列。完整任务历史继续由宿主提供。

### 图例与无障碍

首次图例采用非模态说明，不自动移焦。插件可见且任务跟随开启、当前配置范围尚未确认过图例时显示。用户明确关闭后记录已看过，临时离开不算确认。

已看过标记是同一宿主配置范围内的本地界面偏好，不上传、不属于场景参数。模拟预览不修改它。存储不可用允许下次重显，不影响配置保存。设置始终提供键盘可访问的重开入口。

图例列出符号和文字，明确空闲不等于成功，结果提示仅针对观察到的后台任务转换。

Canvas 保持装饰属性。等价状态区域位于隐藏装饰子树之外，复用同一状态数据和优先级，提供可查询的任务名称、状态及未分配鲸鱼的任务数量。视觉汇总的任务不能从文本中丢失。

摘要和播报分开。等待用户、后台任务完成和失败的新转换使用礼貌播报。持续运行、空闲、运动帧和无关列表更新不反复播报。短时间多次重要转换合并为摘要，保留名称或可查询入口。

名称变化更新摘要但不重复播报任务结论。首次进入可查询当前等待状态，不补播历史结果。切会话、关闭任务跟随和卸载清理待播报队列。关闭任务跟随后不订阅后台任务结果或播报任务状态，图例仍可手动查看。

名称按纯文本处理。视觉可截断长名称，等价文本保留完整名称。空名称采用本地化任务类型替代。新增文案同时覆盖简体中文与 English。不抢输入焦点，不重复制造宿主强制通知。

### 场景参数与设置层级

提供默认、雨天、极简、夜航。夜航只组合已有配色和海面效果，不新增极光。下表是待审阅的建议值，按完整组合应用，不顺序叠加。

| 场景拥有参数 | 默认 | 雨天 | 极简 | 夜航 |
| --- | --- | --- | --- | --- |
| 鲸数 | 3 | 3 | 1 | 3 |
| 游速 | 0.65 | 0.55 | 0.40 | 0.50 |
| 浓度 | 0.60 | 0.55 | 0.35 | 0.45 |
| 配色 | 深海蓝 | 深海蓝 | 深海蓝 | 靛蓝 |
| 风纹 | 开 | 开 | 关 | 开 |
| 云影 | 开 | 开 | 关 | 开 |
| 尾流与水花 | 开 | 开 | 关 | 开 |
| 喷气 | 开 | 关 | 关 | 开 |
| 落雨 | 关 | 开 | 关 | 关 |
| 雨量 | 0.45 | 0.35 | 0.45 | 0.45 |

只修改上表参数。保留草稿中的插件总开关、鱼身文字、填充内容、鲸类、渲染样式、字符大小、鲸鱼大小、左侧留白、任务跟随、全部阅读保护、滚动暂退和资源档位。

1.0.0 新增的「海面方格」与「听写联动」是保护项，不属于场景拥有的十字段：场景不修改、不重置两者的保存值；默认场景只恢复表内组合，也不改变这两个字段。

默认场景只恢复表内组合，不等于恢复全部默认值。全部重置仍只改草稿，第二组加入后将档位重置为标准，不重置独立的图例偏好。

首层展示总开关、场景、鱼身文字、任务跟随、图例入口、保存状态及第二组的资源档位。滑杆和其余细项默认折叠在高级设置。原有可见字段仍可访问且不重复展示。

场景选择一次性更新配置草稿及预览，不自动保存。正式背景保存成功前保持已保存值。由规范化后的表内参数匹配场景名，否则显示自定义。保护项变化不改变匹配结果。浮点按配置步长比较，不另存控制运行结果的场景身份。

### 配置保留规则

| 操作 | 契约 |
| --- | --- |
| 旧配置载入 | 保留有效值，仅缺少的新设置补默认；缺少档位用标准，不自动套预设 |
| 场景选择 | 仅改表内草稿参数，保留其他项，标记未保存 |
| 手动调整 | 沿用校验和互斥，更新草稿预览，不直接影响正式背景 |
| 保存成功 | 仅提交实际差异，采用宿主新版本，清除未保存标记 |
| 失败或冲突 | 保留完整草稿及错误提示，不覆盖新版本，不自动重试覆盖 |
| 重新载入 | 明确放弃草稿，获取已保存值与版本 |
| 恢复默认值 | 仅改草稿，区别于默认场景 |
| 资源切换 | 不改写速度、雨量、鲸数或场景参数 |
| 场景切换 | 不覆盖资源档位 |
| 无关宿主保存 | 配置值相同不重启鲸群 |

内容框毛玻璃和输入框避让沿用互斥：编辑时最后开启者优先，旧数据加载沿用既有规范化及迁移。文字边缘效果独立。场景不改写阅读偏好。

减少动态效果只影响当前运行，不写回资源选择，解除后恢复用户档位。状态或档位变化不重新挂载画布、不重新随机颜色。结构参数变化允许重建必要几何，已有鲸鱼接续位置、朝向、颜色和任务绑定。

### 介绍与演示

中英文开头前置任务跟随与状态演示，再介绍造型和海面。对外使用文字蓝鲸与 ASCII Whales，技术标识不改。

演示覆盖运行、等待、后台任务完成和失败。成功与失败使用不同任务或分明片段，不伪造同一任务先成功后失败。说明可以关闭联动、提示不替代宿主记录、不代用户回答或审批。

最终录屏使用真实安装的 DSH 构建，标明构建身份和条件。独立预览可提供确定性模拟，但页面与素材必须注明模拟。两者复用正式渲染器。截图覆盖场景、图例及中英文主要界面。动图配文字和静态图例，无需观看动画也能理解。

### 省资源模式

标准档默认兼容。两档均遵守隐藏暂停、减少动态效果静态化、禁用释放和滚动暂退。下列数字是拟议预算，不是实测。

| 项目 | 标准 | 省资源 |
| --- | --- | --- |
| 持续绘制上限 | 当前约每秒 30 次预算 | 每秒不超过 15 次 |
| 持续调度 | 兼容现有表现 | 实际减少唤醒与仿真工作，不能只跳过绘制 |
| 运动 | 用户游速 | 运行时采用用户游速的 0.75 倍，保存值不变 |
| 状态 | 事件驱动 | 同样事件驱动，不等低频动画 |
| 布局或状态刷新 | 必要时单次更新 | 必要时单次更新，不重启高频循环 |

允许降低海面效果的运行时采样和并发预算，保留保存的开关与雨量。具体视觉预算由实现对照确定，不破坏阅读、媒体、输入框保护及碰撞避让。

只减少外层推进调用、每次补回相同内部子步，不足以证明仿真工作减少。测量区分持续唤醒、内部推进、绘制与布局。慢漂移不减慢状态响应或改变提示寿命。

前台可见且未处于滚动暂退时，重要状态不等待下一次动画更新。计时起点是宿主状态事件送达插件订阅回调的时刻，分别测量等价文本提交完成和必要 Canvas 绘制完成，两个终点均须在 250 毫秒内达到。该预算不含宿主产生事件前的网络延迟，也不保证读屏开始发声时间。系统减少动态效果仍须单次静态重绘。滚动暂退期间及时更新文本，画面在暂退结束后反映最新状态，不强制提前恢复装饰层。

同一批突发事件合并刷新，保留重要转换摘要，不能通过重置等待时间无限延后提交。持续动画绘制与事件、布局触发的单次绘制分别计数。15 次每秒上限约束无外部事件和布局变化的稳定持续动画，必要单次刷新不计入该上限，但其工作量必须进入总体资源报告。

1.0.0 新增的「海面方格」属于静态海面底层，不读时钟、不随暂停推进，不计入持续动画上限；「听写联动」是外部事件源，省资源档照常以单次绘制响应，不为它保留高频循环。合并后构建须按实际测量确认这两项没有抬高持续唤醒或持续绘制计数。

运行时倍率独立于保存值的范围校验，最低保存游速 0.30 在省资源档的有效游速为 0.225，不被保存配置的下限截回。两档的提示时钟不乘运动倍率，固定内部子步的优化仍须保持避让和动作接续契约。

隐藏时不持续仿真或绘制。预览明确暂停时停止其持续调度，改配置可单次静态刷新。暂停不能只设置零游速，恢复不补算暂停运动。

### 验收条件

第一组如下。

- [ ] G1-01：首次图例不抢焦点，明确关闭后不重复，设置可重开。

## Testing Decisions

### 接口与边界草案

本节随规格审阅，不代表已确认测试接口或通过验收。优先现有最高层接口，不为测试发布新宿主服务或外部引擎 API。

主接口为正式插件设置表单及宿主会话、状态与后台任务服务。从用户操作和状态事件输入，观察配置写入、文本摘要、Canvas 输出和资源释放。独立预览用于受控比较，不代替真实 DSH。

既有先例包括正式构建产物配对、设置表单适配器、配置版本冲突、身份与结果转换、仿真接续、可控时间和页面可见性夹具。沿用这些接口，必要时增加测试专用时间和工作计数适配器，不作为公共 API。

现有设置表单适配器不执行完整 effect，不能独自证明外部版本更新、实时预览和焦点行为，需用实际挂载或真实界面补足。产物夹具需扩展等价文本观测、缺能力组合、绘制历史与实际工作计数。补测最低游速倍率、两档六秒寿命一致、减少动态效果下寿命冻结但状态仍刷新，以及突发状态合并。

测试断言用户结果，不固定私有变量、组件嵌套或旧分组数量。布局改变后保留字段可访问、键盘语义与保存协议检查，不保留失效结构断言。

### 逻辑及真实界面

逻辑覆盖状态转换、历史与重复、会话切换、超额与不可用、图例偏好、长名称和空名称、场景保护、保存冲突、只读、迁移、暂停、响应预算与提示时钟。修改浏览器实现后先构建和生成预览，再执行 `pnpm verify`。

真实 DSH 记录插件来源、构建、宿主版本、页面、视口与系统偏好。指针和键盘检查图例、场景、高级设置、保存、放弃草稿及档位。视觉检查主题、长名称、八头鲸、超额任务、阅读区、媒体和输入框。

至少使用一套实际浏览器与屏幕阅读器组合，记录版本，检查可查询摘要、重要转换去重、不抢焦点。属性自动检查不替代读屏。逻辑、真实交互、视觉、读屏与性能证据分别记录，缺失记未测。

### 可复现资源测量

测量入口提供固定种子、视口、配置、内容与确定性事件时间表。默认不发起真实模型请求，用固定批次追加文本模拟生成并明确标注。真实模型补充观测需另有授权，不与确定性场景混为同组。

同一表面比较关闭、标准、省资源。关闭条件保留相同宿主内容，只移除插件工作，不能替换为空白页。

至少覆盖静止阅读、固定批次追加文本、固定速度滚动。每类比较三条件，保持鲸数、配色、雨量、阅读保护和内容相同。另以八头鲸和落雨做压力检查，不把不同视觉配置混作同组。

每采样单元预热 30 秒、正式采样 60 秒，至少三轮配对比较，轮换并记录顺序。首次编译和初始化单列，保存全部轮次。

记录系统、CPU、GPU、内存、刷新率、宿主或浏览器版本、硬件加速、视口、像素比、电源模式、可见性、构建身份与明显后台负载。

| 指标 | 口径 |
| --- | --- |
| 插件工作 | 持续唤醒、实际内部推进、绘制、布局测量及累计执行时间，外层调用数不替代内部工作 |
| CPU | 可归属进程的 CPU 时间增量、时长、逻辑处理器数；百分比说明单核或整机归一化 |
| GPU | 记录进程及引擎归属、工具和采样口径；整机值不冒充插件独占 |
| 流畅性 | 实际绘制间隔、长任务与状态延迟，预算不当实测帧率 |
| 能耗 | 仅有功率或受控电池数据时报告方法与限制，不由占用率换算续航 |

保存环境、配置、事件表、原始采样、异常及汇总。报告每轮、中位数和范围，不只给百分比。失败返回明确失败状态，缺失数据不填零。GPU 和能耗不可测保留未测字段。

受控页面和真实 DSH 分别汇总。真实 DSH 至少补测静止阅读和滚动，预览数字不写成宿主实测。共享进程或后台干扰无法归属时注明限制并重新配对。

通过条件先要求同配置下持续唤醒、绘制及实际仿真工作减少，状态响应满足预算。再比较重复采样的动画执行时间和进程 CPU。收益不稳定、被噪声覆盖或有可复现回退时记未证实并调查，不能仅靠帧率计数宣称成功。

不预设占用率或续航提升。公开介绍只引用有效原始测量，附范围与复跑方式。没有能耗证据使用省资源表述。
