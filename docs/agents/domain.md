# Domain docs

本仓库采用 single-context 布局，共用一份术语表和一组架构决策记录。

## 探索代码前

- 读取根目录 `GLOSSARY.md`。
- 读取 `docs/adr/` 中与当前任务相关的架构决策记录。

这些文档尚不存在时，直接继续工作。
由 domain-modeling 技能在术语或决策得到明确结论时按需创建。

## 使用术语

任务标题、重构建议、假设和测试名称中的领域概念，采用术语表定义的名称。
需要的概念尚未收录时，先核对项目现有用语；确有缺口则留给 domain-modeling 补充。

## 决策冲突

建议与已有架构决策冲突时，明确指出对应 ADR，并说明重新考虑的理由。
