## 恢复后的步骤

1. **确认来源与授权**：记录候选构建身份（commit、client SHA-256、构建方式）；确认安装到哪个 profile、如何回滚（先备份 profile 配置）；对外安装、发布仍按授权范围处理。
2. **真实指针与键盘**：在设置的场景预设、保存、重新载入、只读状态、深浅主题间走查；检查首次图例不抢焦点、可关闭可重开、关闭后不重复；资源档位切换与暂停；记录控件路径、主题、窗口尺寸与操作结果。
3. **读屏组合**：至少一套实际读屏；确认图例与摘要可达、重要状态转换只播报一次、突发转换合并、运动帧与持续运行不逐帧播报、关闭联动与卸载后不再播报；记录读屏版本、浏览器/宿主版本、操作步骤。
4. **视觉与阅读保护**：真实对话页的正文、代码、输入框、右侧栏、媒体遮挡；深浅主题；长时间游动与任务状态徽记在真实内容上的可读性。
5. **性能（若要做资源结论）**：在真实 DSH 的静止阅读与固定速度滚动上，按测量协议分别取得关闭/标准/省资源数据（同构建、固定种子、固定内容与事件表）；记录环境、电源与后台负载。GPU 利用率与能耗仍保持未测，不推算续航。
6. **记录与回填**：证据分列逻辑、指针、视觉、读屏与性能；截图/录屏注明插件来源与构建；原始文件留本地忽略目录，公开材料只用白名单聚合。逐条回填 #1、#2、#3、#5、#6 的验收项后关票。

## 禁止

- 用独立预览、模拟夹具、headless 或单元测试冒充真实宿主证据。
- 把未测的读屏、GPU、能耗写成通过或换算成省电比例。
- 猜测、导出或绕过 GUI 认证；未经授权重启独占桌面配置或安装插件。
