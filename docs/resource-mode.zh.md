# 资源档位的运行规则与验证

主设置中的「资源档位 / Resource mode」提供标准和省资源两档。选择只修改草稿与预览；保存后应用到背景。保存失败或冲突保留草稿，「重新载入已保存值」放弃草稿，「恢复全部默认值」恢复标准档。旧配置和非法枚举值均回退到标准档。

`resourceMode` 保存值为 `standard` 或 `economy`。它属于正式配置字段，不属于场景预设；四种场景均保留当前档位。首次图例的隐藏宿主偏好 `legendSeen` 仍由独立保存协议维护，不进入视觉草稿或重置。

## 调度与时钟

[src/resource-policy.js](../src/resource-policy.js) 是运行时策略的唯一表。标准档保留 RAF 驱动、约 30 Hz 持续绘制预算和 1/60 秒固定积分。省资源档用定时器驱动，持续回调间隔至少为约 66.7 毫秒，连续绘制不超过 15 Hz；物理积分量子为 1/30 秒，雨效按较粗间隔采样。定时器在本次回调完成后排下一次，不用显示器频率的 RAF 唤醒来跳过绘制。设备较忙时回调可以更少，这些值是预算而非设备帧率承诺。

渲染器用一个带 `raf`／`timer` 类型的状态拥有持续调度句柄，独立单次 RAF 拥有状态和布局刷新。切档先取消旧调度再启动当前档位。第一个状态事件立即绘制，同一帧内后续事件合并到单次刷新；静态姿态也更新。布局刷新另计，不借此恢复持续循环。连续绘制、状态绘制和布局测量均由实际执行位置计数。

省资源游速在保存值校验完成后乘 0.75，随后直接进入运动控制器，保持保存值不变。最低保存值 0.30 对应约 0.225 的有效值，不再经过配置下限。世界、天气和结果提示时钟不乘游速倍率；六秒结果寿命继续按已执行的世界仿真时间计算。档位切换保留鲸体和任务绑定，重建场景继承位置、配色、动作、世界时钟、积分余量及提示的剩余寿命。

预览暂停停止真实持续调度。暂停中的配置调整只刷新静态画面。减少动态效果优先于档位，停止运动但保留状态刷新。隐藏、禁用和滚动暂退取消已拥有的动画句柄并断开装饰观察器，恢复时重新测量，不补算暂停期间的运动。滚动暂退期间等价文字继续接收状态，Canvas 在暂退结束后显示最新状态。卸载还释放监听、定时器及仿真。文字使用同一个任务跟踪器，不随档位创建第二套状态。

## 可复跑检查

使用项目锁定的 Node 与 pnpm：

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm preview
pnpm verify
node scripts/resource-smoke.mjs
```

[冒烟入口](../scripts/resource-smoke.mjs) 在独立 Chrome profile 中使用正式渲染器，正常 GPU 配置、显式 headless、1280 × 800、固定种子、同一配置（最低保存游速、开启落雨）。两档交替采样五轮，每个样本约两秒。每轮验证实际 Canvas 像素、错误、可见性、持续唤醒、真实物理积分、雨效内部推进、水与大气更新和绘制时间表，并检查事件刷新、减少动态效果、暂停及卸载。原始结果和源文件散列写入本 worktree 新建的 `.scratch/resource-smoke-*` 目录。

文本探针只记录夹具 `onActivityChange` 同步写入 DOM 镜像的时刻，没有执行 React。Canvas 探针记录正式渲染器完成绘制的时刻。两者只能证明渲染器路径的诊断阈值，不能判定正式 G2-04 文本提交预算通过。逻辑测试使用模拟 React 适配器和可控时钟，覆盖设置草稿、生成产物、60／120 Hz 时钟、调度通道、提示截止时间、避让和长时间下潜。真实 React 提交由独立挂载夹具另行观察，实际 DSH 与读屏仍未验证。

此入口仅证明候选构建执行了较少工作，不报告 CPU、GPU 利用率、功率、续航或完整资源收益。[三条件入口](./measurement.zh.md)现已支持 OFF、标准和省资源，完整收益判断仍需最终构建的重复采样与独立剖析。实际 DSH 的插件来源、保存交互和 reader 验收仍待宿主可访问后验证。独立 Chrome 或 Ego 夹具不能替代这些证据。
